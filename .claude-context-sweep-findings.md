# Context Sweep Findings

This file collects contradictions, redundancies, and QA gaps discovered during systematic sweeps of `~/.agents/` and `~/.claude/`. Each finding is a full entry with justification, not a scattered ad-hoc note — the same format and approval gate as `~/.claude/suggestions.md`, but separate so architecture/optimization findings and context/contradiction findings don't mix.

Entry format:

```
## [date] [title]

**Category**: contradiction | redundancy | qa-gap

**Files**: 
- file-path-1
- file-path-2

**Status**: pending

**Why**: [motivation — why this matters]

**What**: [description of the issue]

**How**: [concrete resolution path]
```
