## Decisions

<!-- marvin:decisions -->
### quarantine-counts-as-produced: Does a quarantined (but not failed) digest count as "the Mini produced it"?
- [ ] A: Quarantined counts as produced — the Mini did its job; a held-back item is a safety-check outcome, not an outage. The laptop never rebuilds just because content got quarantined. (This is what the code does today.)
- [ ] B: Quarantined counts as not produced — if the brief chain got nothing usable, the laptop should still try, in case its own run clears the safety check.

### retire-cross-machine-merge: Remove `cross_machine_merge.py`'s LLM digest/research-digest merge step now, or leave it in place?
- [ ] A: Remove `run_merge_authority()`'s daily-digest/research-digest loop now — it already runs zero LLM calls on a normal day, so removing it only removes dead code, not behavior.
- [ ] B: Leave it in place for now (current code) and remove it in a separate follow-up ticket.

### brief-schedule-margin: Morning brief at 09:15 leaves 15 min after the 09:00 research colony starts (optional)
- [ ] A: Keep 09:15 (what's implemented today). `write()`'s idempotency means a brief built before the research digest lands just skips that morning's "one idea from research" line.
- [ ] B: Push the Mini's morning-brief schedule later (e.g. 09:25) for a safer margin.
